Built it, then gave it away

neuDB started as a complaint, not a project. I kept getting tired of staring at a black box at 1am, wondering what an agent had actually remembered.

So I wrote a database where you can cat any table and see everything. Zero dependencies, human-readable files, published to PyPI so other people could use it.

I use AI tools. I don't hand over the architecture.

This is roughly how it actually goes.

Here's a retry policy with exponential backoff and jitter, plus a test for the happy path.

Keep the backoff. But move the dedupe guarantee into a UNIQUE constraint — the app-level check is wrong under concurrency, and it will confidently lie to you.

Now write the test that points two real workers at the same rows. Not a mocked race — an actual one.

Added test_concurrent_claimers_receive_disjoint_rows. 73 tests pass, claims come back disjoint.

The tools move faster. The architecture, the tests, and the trade-offs are mine. That's the whole arrangement — and honestly, the part where I learn the most is watching my own test catch my own bug.
